# Persona Blueprint: Brenda - Tech Novice User (Age 54)

**Target Archetype:** Digital Beginner with High Computer Anxiety & Literal Mindset  
**Audience:** Users with low digital literacy who use computers only for essential tasks, fear "breaking the system" or making mistakes, cannot recognize unlabelled abstract icons (hamburger menus, funnels), and panic when encountering technical jargon or cryptic errors.

---

### Persona: Brenda - Tech Novice User
- **Experience Level:** Beginner / Novice
- **Device & Interaction:** Standard Desktop / Laptop Browser
- **Primary Goal:** Follow simple, clearly guided workflows with plain-language instructions, easily locate navigation via visible text labels, and complete forms without fear of errors.
- **Likely Difficulties:** Technical jargon ("404", "Regex", "Payload"), unlabelled icons (three-line hamburger, funnels, gear), multi-step forms without progress bars, silent form errors that don't point to the missing field.
- **Accessibility & Usability Needs:** Plain Language Microcopy, Visible Text Labels on All Navigation Icons, Step-by-Step Progress Indicators, Inline Error Recovery Guidance.

#### Assigned Tasks:
1. **Navigate Website via Clearly Labeled Navigation**:
   - **Objective:** Locate primary services, products, or information using visible text navigation links rather than ambiguous icons.
   - **Starting Conditions:** Starts on homepage.
   - **Observable Success Criteria:** Primary menu opened, category or page selected without confusion.
   - **Evidence to Collect:** Navigation label text, menu toggle affordance.

2. **Complete Form Inputs with Plain-Language Guidance**:
   - **Objective:** Fill out required form fields, following inline instructional text without encountering technical error codes.
   - **Starting Conditions:** Starts on form or entry page.
   - **Observable Success Criteria:** Form fields completed, clear validation messages displayed if errors occur.
   - **Evidence to Collect:** Input field values, validation alert text.

3. **Verify Multi-Step Progress and Completion**:
   - **Objective:** Follow step-by-step progress indicator to final confirmation page with clear feedback.
   - **Starting Conditions:** Starts on multi-step workflow.
   - **Observable Success Criteria:** Progress indicator visible, final confirmation step reached.
   - **Evidence to Collect:** Progress step indicator, confirmation heading.
